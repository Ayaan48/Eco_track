# 🌍 EcoTrack — Personal Carbon Footprint Tracker

EcoTrack is an AI-powered sustainability platform that helps you understand and shrink your
daily carbon footprint. Log your travel, food and home-energy habits in a 3-step form, see a
live CO₂ gauge against a personal carbon budget, browse 30-day trend charts, earn achievement
badges, and get personalised eco-friendly swap suggestions generated by a Groq LLM.

## Features

- **Daily Habit Logger** — 3-step form (travel → food → energy) with a real-time emission preview.
- **Carbon Footprint Calculator** — science-backed coefficients for transport modes, diet types,
  India-grid electricity, heating and AC, computed by the Flask backend.
- **Eco-Friendly Swap Suggestions** — the Groq API (`llama-3.3-70b-versatile`, temperature 0.7,
  max_tokens 800) returns three JSON-structured suggestions with title, description, category and
  estimated CO₂ saving, rendered as styled cards. Curated static tips are used as a fallback.
- **Footprint Trend Dashboard** — Chart.js visualisations: 30-day line chart with a budget
  reference line, 14-day stacked bar chart by category, a colour-coded 30-day heatmap, and a
  summary stat row (7-day average, best day, worst day, monthly total).
- **Personal Carbon Budget** — configurable daily budget (default 8.0 kg CO₂, the global
  sustainable target) shown as an animated SVG gauge that shifts green → amber → red.
- **Streak & Achievement System** — ten badges (First Step, Green Day, 3-Day Streak, Week
  Warrior, Pedal Power, Plant Day, Low Energy, Monthly Hero, Monthly Master, Zero Waster) with
  locked badges shown in greyscale alongside streak progress bars.
- **Carbon Interface Integration** — verified electricity and flight emission estimates, with an
  automatic fallback to local coefficients when the API is unavailable.
- **Demo Mode** — runs fully without Firebase; data is kept in backend memory for the session.

## Architecture

```
React (Vite, :5173) ── Axios ──> Flask API (:5000)
                                   ├── Firebase Firestore  (users, logs, badges)
                                   ├── Groq API            (AI eco suggestions)
                                   └── Carbon Interface    (verified emission data)
Chart.js renders trends; Firebase Auth guards routes (optional — Demo Mode otherwise).
```

### Backend routes

| Route | Method | Purpose |
| --- | --- | --- |
| `/api/health` | GET | Service status |
| `/api/calculate/footprint` | POST | Emission breakdown from habits |
| `/api/habits/log` | POST | Save daily log to Firestore |
| `/api/habits/history` | GET | Last 30 daily logs |
| `/api/habits/today` | GET | Today's log (if any) |
| `/api/habits/settings` | GET/PATCH | User profile settings |
| `/api/habits/badges` | GET/POST | Read / evaluate achievement badges |
| `/api/suggestions/generate` | POST | 3 AI eco suggestions via Groq |
| `/api/carbon/electricity` | POST | Verified electricity estimate |
| `/api/carbon/flight` | POST | Verified flight estimate |

## Getting Started

### Prerequisites

Python 3.9+, Node.js 18+. Optional accounts: [Groq](https://console.groq.com),
[Carbon Interface](https://www.carboninterface.com), [Firebase](https://console.firebase.google.com).

### 1. Backend (Terminal 1)

```bash
cd backend
python -m venv venv
venv\Scripts\activate        # Windows
source venv/bin/activate     # macOS/Linux
pip install -r requirements.txt
cp .env.example .env         # then add your GROQ / Carbon Interface keys
python app.py
```

Flask starts on <http://localhost:5000>. Verify at <http://localhost:5000/api/health>.

### 2. Frontend (Terminal 2)

```bash
cd frontend
npm install
cp .env.example .env         # then add your Firebase web config (optional)
npm run dev
```

Open <http://localhost:5173> for the full dashboard.

### Firebase (optional)

1. Create a Firebase project, enable **Email/Password** auth and **Firestore** (test mode).
2. Download a service account key → save as `backend/serviceAccountKey.json`.
3. Copy the web app config into `frontend/.env` (`VITE_FIREBASE_*`).

Firestore collections created automatically:
`users/{userId}`, `logs/{userId}/daily/{YYYY-MM-DD}`, `badges/{userId}`.

### Demo Mode

If Firebase is not configured, click **“Try Demo Mode”** on the login page — every feature works,
with data stored in backend memory for the session.

> ⚠️ Never commit `.env` files or `serviceAccountKey.json` — both are git-ignored.

## Project Structure

```
backend/
  app.py                     # Flask entry point + /api/health
  firebase_config.py         # Firestore init + Demo Mode memory store
  routes/
    calculator.py            # emission coefficients + footprint calculation
    habits.py                # logs, history, settings, streaks, badges
    suggestions.py           # Groq AI suggestions + fallback tips
    carbon_interface.py      # Carbon Interface estimates + local fallback
frontend/
  src/
    api.js                   # Axios client for all backend calls
    badges.js                # badge/category display metadata
    firebase.js              # optional Firebase web SDK init
    context/AuthContext.jsx  # Firebase auth state + Demo Mode
    components/              # Navbar, GaugeCard, SuggestionCard(+Skeleton), BadgeCard
    pages/                   # Login, Dashboard, LogToday, History, Suggestions,
                             # Achievements, Profile
```
